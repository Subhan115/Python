# Snake Water Gun - v2.0 🐍💧🔫

A terminal-based strategy game featuring predictive AI logic. Developed as a 9th-grade CS project.

## 🕹️ Gameplay
- **Snake** drinks **Water** (Snake wins)
- **Water** douses **Gun** (Water wins)
- **Gun** kills **Snake** (Gun wins)

## 🧠 Logic Features
- **Predictive AI:** In 'Hard' mode, the computer analyzes your pattern to challenge you.
- **Round System:** Play best-of sets (1, 3, 5, or 7).
- **Clean Output:** Designed for a smooth terminal experience in Pydroid 3.

## 🛠️ How to Run
1. Download the `Snake_Water_Gun_Game.py` file.
2. Open it in **Pydroid 3** or any Python IDE.
3. Follow the on-screen instructions.
